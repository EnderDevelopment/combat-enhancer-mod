# Combat Enhancer Mod

Enhance your combat with increased knockback and sprint module.

## Features

- Increased player attack knockback
- Sprint module with custom GUI

## Requirements

- Minecraft 1.8.9
- Forge 11.15.1.2318-1.8.9

## Installation

1. Download the mod file.
2. Place it in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

- Press the 'K' key to open the Combat Enhancer GUI.
- Adjust the knockback multiplier and enable/disable the sprint module.

## Configuration

The mod configuration file is located at `config/CombatEnhancerMod.cfg`. You can adjust the knockback multiplier and enable/disable the sprint module in this file.
